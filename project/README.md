# Credence decentralized academic identity UI

### Note: If you have any concerns or questions please contact me!

This repository currently contains the **Identity & Data** component and a complete
Python frontend for all the team project.

## What is included

- A readable `DigitalIdentity.sol` contract that stores only hashes.
- Deterministic SHA-256 hashing and local JSON off chain storage.
- A Streamlit UI for identity registration, credentials, consent, revocation,
  requester access, audit events, and reward balances.
- Demo mode, so the complete workflow runs before the other contracts are ready.
- Web3 mode, which connects the exact same UI to a local Hardhat node.
- ABI files and a precise interface agreement for teammates.

Testing, deployment, gas measurement, and the other three contract implementations are
currently not implemented.

## Run immediately in demo mode

Python 3.14 or later is recommended.

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\activate
```

Install and run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Right now the demo wallets appear in the sidebar. Use Alice to register an identity and credential,
grant Bob consent, then switch to Bob to attempt access. Switch back to Alice to revoke
consent and repeat Bob's attempt. The audit page will retain both outcomes during the
session.

## Connect to the team's Hardhat contracts

1. Copy `.env.example` to `.env`.
2. Change `APP_MODE=web3`.
3. Start the local Hardhat node.
4. Deploy all your contracts.
5. Put the four deployed addresses in `.env`.
6. Ensure that your contracts match `docs/TEAM_INTERFACE.md`.
7. Run `streamlit run app.py`.

Currently Hardhat exposes unlocked local accounts, so Web3.py can send transactions from the
wallet selected in the sidebar. This is suitable for the required local prototype, not
for production. A production version would use a browser wallet such as MetaMask.

## Recommended team handoff

Each one of us gets a `docs/TEAM_INTERFACE.md` now. When your contract is ready, replace
its JSON file in `abi/` with the ABI generated by Hardhat and add its deployed address
to `.env`. No UI page should need to change if we use this method.

## Privacy and security notes

- Never use real data in this coursework prototype.
- Plaintext identity and credential records should not be submitted to Ethereum.
- A hash proves that a record is unchanged; it does not encrypt the record.
- Local JSON storage is a prototype limitation and is documented in the project plan.
- `.env` and generated local records are excluded by `.gitignore`.
